Course Overview
BIS 015L introduces the fundamentals of data science using examples relevant to biological
research. The course uses the R programming language to teach key skills such as:
Data management and cleaning, Data transformation, Basic analysis, Data visualization

Examples and datasets come from areas including ecology, evolution, genetics, and social science. 
Labs follow a problem-solving approach and build on each other throughout the quarter.
The course concludes with a small group project.

No prior experience with programming, R, or statistics is expected.
